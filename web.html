Jak vytvořit svůj první web

Než se vrhneš na programování, musíš si nejprve vytvořit github účet a nainstalovat Visual Studio Code.

Vytvoření github účtu

  1. Otevři stránku registrace: Otevřít registraci na GitHubu.
  2. Zadej svůj e-mail. Použij adresu, ke které máš přístup.
  3. Vymysli si heslo a uživatelské jméno. Heslo nikomu neříkej.
  4. Dokonči ověření. Postupuj podle pokynů na obrazovce.
  5. Potvrď e-mail. Otevři zprávu od GitHubu a klikni na odkaz.
  6. Přihlas se. Použij e-mail nebo uživatelské jméno a heslo.

Stažení a instalace Visual Studio Code

  1. Otevři stránku pro stažení: Otevřít stažení VS Code.
  2. Vyber svůj systém. Zvol Windows, macOS nebo Linux.
  3. Stáhni soubor. Najdeš ho obvykle ve složce „Stažené soubory“.
  4. Spusť stažený soubor. Otevři složku „Stažené soubory“ a dvakrát klikni na něj.
  5. Nainstaluj program. Postupuj podle pokynů na obrazovce.
  6. Otevři VS Code. Najdi program v nabídce aplikací.
